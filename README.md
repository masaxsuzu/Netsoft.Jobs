# Netsoft.Jobs

Windows ワークステーション上で動作する、長時間実行 Job の共通実行基盤 (Job Execution Engine)。

アプリケーション固有の Job を実行するための基盤であり、エンジン自体は Job の内容に依存しない。

## 現在の状態

設計フェーズ。実装コードはまだ存在しない。

## 前提と範囲

- Windows ワークステーション 1 台 / 利用者 1 人 / クラウド利用なし
- UI はブラウザ、バックエンドと Job 実装は C#
- Job の実行時間は数秒〜数時間
- Pause / Cancel / Retry の対応可否は Job ごとに異なる

スコープ外: クラウド実行、分散実行、複数ユーザ対応、権限管理、成果物ダウンロード、自動復旧、自動再実行、日時スケジューリング。
